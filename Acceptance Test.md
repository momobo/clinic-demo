1. The User checks the wait time on the smartphone, from anywhere, in less than 30 sec without creating an account
2. The User takes the ticket on site (taking a number is only possible on site) and should see the time shortening, not only based on prediction, but also with the current speed of the queue taken into account.
3. The User could drop from the queue with one click, the other user will have time shortened. A cancelled ticket cannot be reinstated; the user must take a new one
4. The Employee start a queue in less than a minute 
5. The Employee (only staff, logged in with the shared password) marks the Patient as served. Should be one or two clicks. The patient is removed by the queue
6. The wait time is calculated, not only for the last patient, but for all of them in the queue. Is immediately transferred where the patient and personnel could see it.
